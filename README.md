# chaomeng-lu.github.io

Personal academic website of **Chaomeng Lu**, PhD researcher at KU Leuven (DistriNet), working on AI-driven software security and LLM-based vulnerability detection.

Live site: <https://chaomeng-lu.github.io>

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme (MIT License). Pushes to `main` are built and deployed to the `gh-pages` branch by GitHub Actions.

## Where to edit

| What                 | File                            |
| -------------------- | ------------------------------- |
| Home page bio        | `_pages/about.md`               |
| Publications         | `_bibliography/papers.bib`      |
| CV page              | `_data/cv.yml`                  |
| CV PDF download      | `assets/pdf/Chaomeng_Lu_CV.pdf` |
| News                 | `_news/*.md`                    |
| Projects             | `_projects/*.md`                |
| Social links / email | `_data/socials.yml`             |
| Site settings        | `_config.yml`                   |
| Profile photo        | `assets/img/prof_pic_color.jpg` |

Template documentation lives in [`docs/`](docs/).

I am a PhD researcher in Computer Science at KU Leuven (DistriNet). My research focuses on AI-driven software security, in particular automated vulnerability detection in C/C++ source code using pre-trained code models, contrastive learning, and large language models (LLMs).

My work spans the full research pipeline:

  • Vulnerability data. I build well-labeled vulnerability datasets from real-world CVEs and fix commits across 800+ GitHub repositories, including SZZ-traced vulnerability-contributing commits (ICVul, MSR 2025).
  • Models. I design detection models that capture the subtle differences between vulnerable and patched code, such as PatchCon, a patch-aware supervised contrastive learning approach.
  • Realistic evaluation. I study how deep learning models and open-weight LLMs perform outside the lab, on newly disclosed Linux kernel and Chromium vulnerabilities (JSS 2026).

I have published as first author in the Journal of Systems and Software, IEEE/ACM MSR, and the IEEE Internet of Things Journal, and I serve on the program committee of the MSR Data and Tool Showcase Track. Before my PhD, I received an M.Sc. in Cyberspace Security, where I worked on meta-learning for few-shot network intrusion detection.

I am open to research and engineering roles in AI, software engineering, and cybersecurity, especially where research methods need to become reliable, production-ready solutions. Feel free to get in touch or take a look at my CV.

selected publications

  1. arXiv
    PatchCon: Patch-aware Weighted Supervised Contrastive Learning for Vulnerability Detection
    Chaomeng Lu, Pooya Rostami Mazrae, and Bert Lagaisse
    arXiv preprint arXiv:2611.06583, Nov 2026
    Under review
    Abs arXiv Bib Code

    PatchCon is a CodeBERT-based vulnerability detection model that jointly optimizes vulnerability classification and supervised contrastive learning, treating vulnerable–patched function pairs as weighted hard negatives so the model learns the subtle, fix-related differences between them. On PairVul-Linux, PatchCon improves pairwise accuracy over the strongest reproduced baseline from 0.21 to 0.33 (+58%), matches a GPT-4o-based LLM method at substantially lower cost, and generalizes best to unseen CVEs and newly disclosed Linux kernel vulnerabilities.

  3. MSR
    ICVul: A Well-labeled C/C++ Vulnerability Dataset with Comprehensive Metadata and VCCs
    Chaomeng Lu, Tianyu Li, Toon Dehaene, and 1 more author
    In 2025 IEEE/ACM 22nd International Conference on Mining Software Repositories (MSR), 2025
    Abs DOI arXiv Bib Code

    ICVul is a C/C++ vulnerability dataset derived from real-world CVEs and their GitHub fix commits across 800+ repositories. It is enriched with function-, file-, and commit-level metadata and with Vulnerability-Contributing Commits (VCCs) traced using the SZZ algorithm.

    Abs DOI Bib Code
